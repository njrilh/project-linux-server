# Linux Web Server Administration 🖥️

**CentOS-Based Web Server Configuration and Administration**

This repository documents a Linux server administration project using CentOS in a virtualized environment.

The project focuses on configuring web services, database services, and essential server administration components.

## ✨ Implemented Components

- CentOS installation and configuration.
- Nginx web server setup.
- MariaDB database installation and configuration.
- PHP environment setup.
- phpMyAdmin configuration.
- SSH remote access.
- Firewall configuration.

- **Operating System:** CentOS Stream 9
- **Virtualization:** Oracle VirtualBox
- **Web Server:** Nginx
- **Database:** MariaDB
- **Backend Environment:** PHP
- **Database Management:** phpMyAdmin
